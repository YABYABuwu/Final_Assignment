# Image Processing & Target Diagnostic Tool (Manual Gimbal)
สำหรับ **RoboMaster EP - Final Assignment**

โฟลเดอร์นี้ถูกแยกออกมาจาก `ColorLockingLAB` เพื่อใช้สำหรับ **ทดสอบและวินิจฉัยการตรวจจับสีและรูปทรง** โดยเฉพาะ โดยเน้นการ **หมุนกิมบอลด้วยมือเอง (Manual Gimbal)** ไม่มีการหมุนติดตามอัตโนมัติ และไม่มีการยิง

ปรับช่วง HSV ของแต่ละสีที่ `config/settings.yaml` → `color_ranges` เครื่องมือนี้อ่านค่าชุดเดียวกับการตรวจเป้าบนกำแพง และต้องเริ่มโปรแกรมใหม่หลังแก้ค่า

---

## 1. วิธีรันโปรแกรม

### วิธีที่ 1: เปิด Web Diagnostic Viewer (แนะนำ — แสดงผลผ่านเบราว์เซอร์)
รันคำสั่งจากโฟลเดอร์ `Final_Assignment`:
```bash
# เมื่อเชื่อมต่อกับหุ่นยนต์ RoboMaster EP ผ่าน Wi-Fi AP
py -3.8 -m img_processing.viewer

# หรือทดสอบกับ Webcam โน้ตบุ๊กบนโต๊ะ
python -m img_processing.viewer
```
เปิดเบราว์เซอร์ที่: **`http://127.0.0.1:8080`**

**จุดเด่นบนหน้าเว็บ:**
- สตรีมภาพกล้องสดพร้อมผลตรวจจับ และภาพ Color Mask ทุกสี
- ปุ่มสลับโหมด **Robust (แก้ระยะชิด)** กับ **Classic (เดิมของ ColorLockingLAB)** เพื่อดูความแตกต่างแบบ Real-time
- ปุ่มเปิด/ปิด **แก้เลนส์โค้ง (Undistort)**
- ปุ่ม **ปลดกิมบอลหมุนด้วยมือ (Gimbal Suspend)** มอเตอร์จะเข้าสู่โหมดพัก (Sleep) ทำให้เราสามารถใช้มือจับกิมบอลหมุนไปทางต่างๆ ได้อย่างนุ่มนวล โดยไม่ฝืนแรงต้านของมอเตอร์และเฟืองไม่พัง
- ตารางแจกแจงค่าการวัดละเอียด: Area, Circularity, Ellipse Fit Ratio, Aspect Ratio, จำนวนมุม, และสถานะ PASS/REJECT

## 2. การวิเคราะห์ปัญหา: ทำไมระยะชิดในช่องกระเบื้องเดียวกันจึงทำให้รูปทรงผิดเพี้ยน?

เมื่อหุ่นยนต์อยู่ในช่องกระเบื้องเดียวกับกำแพงที่มีป้ายเป้าหมาย (กระเบื้องขนาด 60 × 60 ซม.):
1. **ระยะเลนส์ถึงป้ายสั้นมาก (Extreme Proximity)**:
   - กึ่งกลางตัวรถห่างจากกำแพง 30 ซม.
   - โครงสร้างชุดกิมบอลและลำกล้องยื่นออกไปด้านหน้าประมาณ 15–20 ซม.
   - เมื่อกิมบอลหันข้าง 90° เข้าหากำแพง ระยะห่างจากหน้าเลนส์ถึงแผ่นป้ายจะเหลือเพียง **10–15 ซม.!**
2. **ความบิดเบี้ยวของเลนส์มุมกว้าง (Wide-angle Barrel Distortion)**:
   - กล้อง RoboMaster EP มีมุมมองกว้าง (FOV ~120°) เลนส์มุมกว้างจะดึงภาพที่ขอบให้โค้งออกเหมือนถังเบียร์ (Barrel Distortion)
   - ป้ายที่อยู่ใกล้จะขยายใหญ่เต็มเกือบทั้งจอ (พื้นที่ > 20,000 px) ทำให้ขอบของป้ายตกอยู่ในบริเวณที่เลนส์บิดเบี้ยวสูงสุด
   - เส้นตรงของขอบสี่เหลี่ยมจะโค้งงอ ทำให้ `cv2.approxPolyDP` ตีความเป็น 5–8 มุม ส่งผลให้เงื่อนไข `len(corners) == 4` ตกทันที
3. **การเพี้ยนจากมุมมองเฉียง (Perspective Foreshortening / Keystone Distortion)**:
   - หากแนวมุมมองกล้องไม่ได้ตั้งฉากระนาบป้าย 100% (กิมบอลเอียง yaw หรือ pitch เล็กน้อย):
     - **สี่เหลี่ยมจัตุรัสจะกลายเป็น "สี่เหลี่ยมคางหมู" (Trapezoid)** ด้านที่ใกล้เลนส์จะกว้างกว่าด้านที่ไกลเลนส์ อัตราส่วนด้าน `min/max` จะตกลงมาอยู่ที่ 0.70–0.80 ทำให้โค้ดเดิมที่ตรวจ `ratio >= 0.85` ตัดสินผิดเป็น "ผืนผ้า" หรือตัดทิ้งเพราะ `area / minAreaRect < 0.78`
     - **วงกลมจะกลายเป็น "วงรี" (Ellipse)** โดยอัตราส่วนแกนสั้น/ยาว (Aspect Ratio) และ Circularity ($4\pi A / P^2$) จะตกลงมาต่ำกว่า 0.70 ทำให้โค้ดเดิม REJECT วงกลมทิ้ง
4. **แสงสะท้อนและเงาบัง (Glare & Shadows)**:
   - เมื่ออยู่ใกล้มาก กิมบอลของหุ่นอาจบังแสงไฟเพดานจนเกิดเงา หรือสารเคลือบผิวป้ายสะท้อนแสงวาบ ทำให้เกิดรอยแหว่งใน Color Mask

## 3. วิธีแก้ปัญหา (Solutions)

โมดูลนี้ได้สร้างอัลกอริทึม **Robust Mode** และข้อแนะนำเชิงตำแหน่งเพื่อแก้ปัญหาดังกล่าวอย่างสมบูรณ์:

### 3.1 การแก้ด้วยอัลกอริทึม Image Processing & Computer Vision

1. **การดัดเลนส์โค้งให้ตรง (Camera Undistortion)**:
   - ใน `detector.py` ใช้ฟังก์ชัน `undistort_frame()` โดยป้อนพารามิเตอร์ Intrinsic Matrix ($K$) และ Distortion Coefficients ($D = [k_1, k_2, p_1, p_2, k_3]$) ของกล้อง RoboMaster EP
   - ช่วยดึงเส้นขอบที่ป่องโค้งให้กลับมาเป็นเส้นตรง ส่งผลให้ `approxPolyDP` ตัดขอบได้ 4 มุมตรงเผง
2. **การฟิตวงรีแทนการตรวจความกลมคงที่ (Direct Least Squares Ellipse Fitting)**:
   - ตามหลัก Projective Geometry วงกลมที่ถูกมองจากมุมเฉียงใดๆ จะยังคงมีรูปทรงทางเรขาคณิตเป็น **วงรี (Ellipse)** เสมอ
   - ใช้ `cv2.fitEllipse(contour)` เพื่อหาแกนยาวและแกนสั้น ($d_1, d_2$)
   - คำนวณพื้นที่วงรีในอุดมคติ: $A_{\text{ellipse}} = \frac{\pi}{4} \cdot d_1 \cdot d_2$
   - ตรวจอัตราส่วน $\frac{A_{\text{contour}}}{A_{\text{ellipse}}}$ ซึ่งจะอยู่ในช่วง **0.85 – 1.15 เสมอ** แม้จะมองเฉียงถึง 60° ก็ตาม
3. **การใช้ Convex Hull + Adaptive Epsilon กับสี่เหลี่ยม**:
   - นำ Contour ผ่าน `cv2.convexHull()` ก่อนเสมอ เพื่อลบรอยเว้าและขอบหยักจากแสงสะท้อน
   - วนลูปทดสอบค่า $\epsilon$ ในช่วง $0.02 \times P$ ถึง $0.05 \times P$ เพื่อควบรวมเส้นโค้งของเลนส์ให้กลายเป็นมุม 4 มุมที่แท้จริง
4. **Perspective-Tolerant Quadrilateral Classification**:
   - ตรวจสอบมุมภายในของ 4 มุมให้อยู่ในช่วงเฉียงที่ยอมรับได้ ($50^\circ - 130^\circ$)
   - ปรับเกณฑ์ Fill Ratio ของ MinAreaRect ลงมาเป็น $\ge 0.70$ (เพื่อยอมรับรูปสี่เหลี่ยมคางหมูที่เกิดจากการมองใกล้)
   - ปรับเกณฑ์ Square Ratio ผ่อนปรนลงมาเป็น $\ge 0.80$ หรือคำนวณจากความยาวเฉลี่ยของคู่ด้านตรงข้าม

---

### 3.2 การแก้ด้วยการควบคุมตำแหน่งหุ่นยนต์ (Robot Positioning / Standoff Strategy)

หากนำไปเชื่อมต่อกับโปรแกรมการเดินจริง (เช่น `run_round2.py`):
1. **การตั้งระยะ Standoff Distance (ถอยรถก่อนหันกิมบอล)**:
   - ใน `run_round2.py` มีอาร์กิวเมนต์ `--standoff 0.20`
   - เมื่อหุ่นยนต์ต้องตรวจหรือยิงป้ายในช่องกระเบื้องเดียวกัน **อย่าจอดรถตรงกลางช่องพอดี** เพราะระยะเลนส์ถึงผนังจะเหลือแค่ 10–15 ซม.
   - ควรสไลด์รถถอยห่างจากผนังเป้าหมายออกมาอีก 20–25 ซม. (ขยับไปอยู่ขอบอีกฝั่งของแผ่นกระเบื้อง) จะทำให้ระยะเลนส์ถึงป้ายเพิ่มเป็น **35–40 ซม.**
   - ที่ระยะ 35–40 ซม. ภาพจะอยู่ในระยะโฟกัสที่คมชัด ป้ายไม่ล้นจอ และความบิดเบี้ยวของเลนส์ลดลงไปมากกว่า 70%!
2. **การจัดเป้าให้อยู่กึ่งกลางภาพ (Centering before Shape Decision)**:
   - เลนส์มุมกว้างมีความบิดเบี้ยวต่ำสุดบริเวณกึ่งกลางภาพ (Optical Center)
   - หากตรวจจับสีได้ที่ขอบภาพ ให้ขยับกิมบอลให้จุดศูนย์กลางของสีมาอยู่ใกล้กึ่งกลางภาพก่อน จึงทำการตัดสินรูปทรง
